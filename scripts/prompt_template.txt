★ 本提示词是【唯一文风契约】：无论由哪一个模型执行，产出必须在文风、语气、人称、详略程度、术语使用上完全一致，读者不应能分辨出某一场是哪一个模型写的。

零、角色与术语规范（强制对照表，优先级高于以下所有章节）：
1. 本场唯一主角一律称「{streamer}」。禁止使用「主播」「UP主」「up主」「她」「他」「小姐姐」「女孩」等任何其它指称；需要指代时重复「{streamer}」，不用代词。
2. 观众群体一律称「{audience}」。禁止使用「观众」「粉丝」「网友」「大家」「家人们」「弹幕们」「水友」等其它叫法。
3. 需要区分个体或部分观众时写「有{audience}」「部分{audience}」「{audience}中有人」，禁止虚构 ID 或昵称。
4. 以下为中性名词，不属于人物指称，可正常使用：直播间、弹幕、礼物、舰长、提督、SC、平台名、歌曲名、游戏名、作品名。
5. 作品名、游戏名、歌曲名、人名：使用通用译名或原文（日文/英文）片假名与英文原名，全文保持一致；同一事物不得中途换名，首次出现后可用同一简称。
6. 数字与单位用半角阿拉伯数字（如 3 分钟、30%）；中文标点一律全角。

一、分段规则：
通读全文后按语义重新分段，不必遵循原文换行；在语义出现明显转折、话题切换或时间变化时必须断开为新段；同一时间内信息过多可拆分为多段但时间需保持一致；禁止按句机械拆分，必须基于语义组织段落；禁止因细节增加而过度拆段。

二、时间标注规则：
必须先提取全文所有时间节点，形成时间序列后再开始写总结；时间节点包括明确时间、相对时间、事件顺序提示（如“刚才”“后来”“过了一会”等）；每一段开头必须标注一次时间，格式为：[HH:MM:SS]。
时间分配规则：若段落对应明确时间则使用该时间；若无新时间且属于上一个时间段则继承上一个时间；若出现模糊时间必须作为新时间节点使用；严禁所有段落使用同一个时间（除非全文确实只有一个时间）；若无法判断时间，必须使用“时间不明确（位于XX之后）”格式，不得重复已有时间。
时间戳后必须紧跟正文，不得只输出一个时间戳而无内容。
自检机制：输出前检查是否存在连续3段以上时间完全相同，若存在必须重新判断时间划分；检查是否存在时间跳跃但未分段，若存在必须拆段。

三、总结规则（压缩强化与详略统一）：
每段长度严格控制在100–180字；不足80字的段落视为不合格，必须并入相邻段或补足信息点；超过180字必须拆段。
每段必须以“{streamer}”作为主语开头；每段必须以句号结尾；语言通俗简洁且信息完整。
禁止使用指代不清的代词，尤其禁止用“她”“他”回指{streamer}。
语气统一为中性记录式：只陈述事实与行为，不评价、不煽情、不使用感叹号（金句原文除外）、不使用“哈哈”“嘿嘿”“呢～”等拟声与卖萌语气词。
内容表达必须遵循“信息提炼优先”原则：只保留关键事实、核心行为、主要情绪与结论，删除铺垫、重复表达、弱信息、口语填充。
禁止逐句对应原文进行改写，必须进行抽象概括。
单段信息上限：最多包含3–4个关键信息点，超出必须拆段。
禁止使用举例式扩展、解释性补充或主观延伸。

四、内容处理规则：
大段感谢礼物内容统一压缩为“{streamer}感谢{audience}送出的礼物。”；若单段信息过多必须拆分为连续多段，完整覆盖全部关键信息，不得因压缩而遗漏核心内容。

五、风格限制：
尽量避免使用“接着提到 / 然后 / 又 / 最后 / 之后 / 接下来”等连接词；所有推进关系通过分段与时间变化体现，而不是连接词；整体风格偏“记录式摘要”，而非“叙述式还原”。

六、输出格式规范（统一契约，所有模型必须完全一致）：
输出内容只有两种行——「总结行」与「金句行」，除此之外不得输出任何其它内容。
1. 标题层级：不输出任何标题、小标题、章节名或场次名（文档标题由系统生成）；不得用 #、-、数字序号、全角数字等方式自行制造层级。
2. 段落长度：一个总结行就是一个自然段，长度遵循第三节的100–180字约束；一个总结行只写一段，禁止在段内换行。
3. 列表与加粗：禁止使用任何列表符号（- * • ① 1. 1））；禁止使用任何 Markdown 标记（** __ _ ` # >）；粗体、斜体、字号等排版效果由系统自动处理，模型既不得输出格式标记，也不得出现“粗体”“斜体”“加粗”等格式说明字样。
4. 换行：总结行与金句行各占一行，行与行之间用一个换行分隔；禁止连续空行，禁止行尾多余空格。
5. 标点：中文标点统一全角（，。！？：；“”），英文与数字保持半角；每个总结行以句号结尾；引号必须成对且完整，不得截断。
6. 时间戳：每个总结行以 [HH:MM:SS] 开头，方括号内只放时间；除时间标注外不得使用方括号。
7. 分隔符号：禁止输出 -----、===、***、``` 等任何分隔线或包裹符号。
8. 全文使用简体中文；除作品名与专有名词原文外，不使用英文整句。

七、金句摘录规则：
触发条件为该段存在表达力强、情绪突出或观点浓缩的原句，且添加后能明显提升理解。
数量约束（用于保证不同模型的金句密度一致）：每 3–5 个总结行附 1 条金句；整场不得为 0 条，也不得每个总结行都附；相邻两个总结行不得同时附金句。
必须逐字来自原文，不得改写或伪造；长度15–80字，禁止大段复制原文。
金句单独一行放在对应总结行之后，与总结内容之间必须换行；整行以“开头、以”结尾（引号必须成对完整、不得截断），行首行尾不得出现“斜体”“粗体”等格式说明字样或任何其它文字。
禁止为凑数量强行添加金句，禁止连续多段摘抄相似内容，禁止用总结句伪装原文。

八、严格执行要求：
不得遗漏关键信息，不得偷懒简化；信息过多时优先拆段而不是扩写；所有规则必须同时满足；若输出出现冗长、解释性或接近原文复述，必须重新压缩。
